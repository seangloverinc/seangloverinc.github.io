I'm pleased to announce the publication of my first book,
[*Designing Fast Data Application Architectures*](/assets/designing-fast-data-app-architectures.pdf),
co-authored with [Gerard Maas](https://www.linkedin.com/in/gerardmaas) and Stavros Kontopoulos, and published by [O'Reilly Media](https://www.oreilly.com).

The book is a practical guide to building streaming and fast data systems with the
[SMACK](https://www.oreilly.com/ideas/a-mini-guide-to-the-smack-stack) stack —
[Apache Spark](https://spark.apache.org), [Apache Mesos](https://mesos.apache.org), [Akka](https://akka.io),
[Apache Cassandra](https://cassandra.apache.org), and [Apache Kafka](https://kafka.apache.org).
It walks through the anatomy of a fast data application — the message backbone, stream processing,
compute engines, and the serving layer — with patterns for event sourcing, topic partitioning,
and processing flows drawn from production experience.
